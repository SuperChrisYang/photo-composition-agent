# 手机拍照构图智能体

一个移动端优先的拍照构图智能体原型。打开页面即可调用手机摄像头，也可以从相册选图；选择场景、点按主体、叠加构图网格后，会自动给出构图方式、相机参数配置和机位调整建议。

## 已实现

- 实时相机预览与拍摄冻结
- 相册图片输入
- 风景 / 人物 / 环境 / 夜景 / 建筑五种场景
- 每个场景的基准参数模板与下次同场景参数模板
- 三分法、黄金分割、对角线、对称构图网格
- 点按画面标记主体
- 基于图像的亮度、对比度、色温、边缘密度和主体位置生成建议
- 构图分数、具体拍摄参数、机位调整、后期修图建议
- 浏览器支持时把 ISO / EV / 白平衡 / 对焦应用到相机轨道
- 关闭相机、启动场景分析、按方案拍摄
- 实时分析：取景过程中自动更新构图建议
- 动态构图引导线：根据场景在取景画面上显示主体目标与引导线
- 导出/分享建议文本
- 嵌入摄影构图 skill：`skills/photography-composition.md`，按识别场景展示对应构图知识
- 自动识别场景：默认“自动”模式根据画面判断人物/风景/环境/夜景/建筑；手动选择场景时以手动选择优先

## 运行

直接用浏览器打开：

```sh
open index.html
```

手机端访问时，摄像头权限需要安全上下文。已提供自签名 HTTPS 服务：

```sh
node tools/serve-https.mjs
```

手机访问 `https://<电脑IP>:8443/`，首次打开时信任自签名证书后即可调用摄像头。启动 HTTPS 服务时会自动打印当前所有局域网 IP；如果之前的 IP 打不开，请改用服务启动日志里最新的 `https://192.168.1.x:8443/` 地址。

桌面调试也可以直接打开 `index.html`，或用 `python3 -m http.server 8000` 提供 HTTP 版本（桌面 localhost 可用摄像头，手机 HTTP 会被浏览器限制）。

首次使用：点击中间红色按钮申请相机权限并打开预览，预览出现后再次点击才拍摄。

也可以点击右上角“点击开启相机”打开预览，然后使用“启动场景分析”对当前画面直接分析；“关闭相机”会释放摄像头权限；“按方案拍摄”会先尝试应用参数再拍摄。

点击“启动场景分析”后按钮会显示“分析中”并暂时禁用；分析完成后显示“分析完成”，随后恢复为“启动场景分析”，可以再次分析。

开启“实时分析”后，取景画面会每 1.5 秒自动采样一次并刷新建议；点击“导出”可以把当前方案通过系统分享或复制为文本。

构图知识来自 [photography-composition skill](/Users/yangshaofei/.agents/skills/photography-composition/SKILL.md)，已嵌入到 `skills/photography-composition.md`，分析结果会显示当前场景对应的构图速查，并可展开查看完整指南。

## 生产版智能体架构

当前原型使用可解释的规则引擎，适合离线演示。生产版可以升级为：

```text
相机预览帧
  -> 本地轻量场景理解（主体检测 / 人脸 / 地平线 / 光影）
  -> 构图规则引擎（三分、引导线、对称、留白）
  -> 手机相机参数映射（ISO、快门、EV、白平衡、对焦）
  -> 机位提示（左右平移、蹲低、靠近、仰角、旋转）
  -> 实时覆盖层与语音/文本建议
```

可选接入 DeepSeek 多模态模型：将预览帧降采样后发送给视觉模型，由模型输出结构化 JSON，再由手机端映射为构图网格和相机参数。

## 直接设置相机参数

Web 页面只能设置浏览器暴露给 `MediaStreamTrack` 的能力，通常是 ISO、EV、白平衡和连续对焦；快门速度、光圈和多数专业参数仍需要系统相机或原生 App 开放 Camera2 / AVFoundation 权限。当前原型在浏览器支持时会自动尝试应用参数，并在不支持时给出明确的手动设置提示。

## 建议的智能体输出结构

```json
{
  "composition": ["rule_of_thirds", "leading_lines", "foreground"],
  "score": 86,
  "camera": {
    "iso": 200,
    "shutter": "1/250",
    "ev": 0,
    "whiteBalance": "auto",
    "focus": "subject"
  },
  "position": ["move_left_0.3m", "crouch", "step_forward"],
  "overlay": {
    "grid": "thirds",
    "subject": [0.33, 0.33],
    "lines": [[0.1, 0.8, 0.9, 0.2]]
  }
}
```

## 后续可以做成 dsh 插件

如果需要把它接入 DeepSeek Harness，可以将 `index.html` 的规则引擎拆成 dsh skill：

```text
photo-composition/
├── package.json
├── cordis.patch.yml
└── skills/
    └── SKILL.md
```

`SKILL.md` 接收用户上传的照片，输出构图、参数与机位建议，并可直接复用本原型的规则逻辑。
